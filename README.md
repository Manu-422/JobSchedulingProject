# Job Scheduling Using Graph

## Project Description
This project implements job scheduling using graph theory and topological sorting in Python.

## Features
- Add and remove jobs
- Add job dependencies
- Generate a valid job execution order
- Detect cycles in dependencies
- Load sample jobs and clear all jobs

## Technologies Used
- Python
- Tkinter
- Graph
- Topological Sorting Algorithm

## How to Run
1. Install Python on your computer.
2. Keep `main.py` and `algorithm.py` in the same folder.
3. Run the following command:

```bash
python main.py
```
